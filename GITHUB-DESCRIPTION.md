📰 **BlogHub** - Full-Stack Role-Based Blogging Platform

Modern blogging app with JWT auth, role-based access (**Public/Writers/Admins**), rich post editor (**React Quill + images**), admin dashboards, protected CRUD. 

**React 19 + Vite + Tailwind** | **Express + MongoDB + Passport**

🔥 **Features**:
• Public post browsing & reading
• Writers: Manage own posts/dashboard  
• Admins: Full control (users/posts)
• Image uploads, rich text, pagination
• Responsive UI w/ GSAP animations

🚀 **Quick Setup**:
```
cd backend && npm i && npm run start:dev  # :5014
cd Blog && npm i && npm run dev           # :5173
```
